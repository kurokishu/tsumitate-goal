# Tsumitate Goal（投資シミュレーター）

何歳から投資すると、60歳・65歳・70歳の日にいくらになるかを、2つの利回りと元本で比べる無料のツールです。副業の税金（2026年分の概算）と、NISAの生涯枠に収まるかも分かります。

- 基準の利回り：全世界株式「MSCI オール・カントリー・ワールド・インデックス（MSCI ACWI）」の2000年12月末〜2026年10月末の年平均 7.31%（MSCI 社の公式資料）をもとにした 7.3%
- 堅実想定の利回り：年金積立金管理運用独立行政法人（GPIF）の2001〜2025年度の年平均 4.67%（GPIF の会見資料）をもとにした 4.6%
- ページ：https://kurokishu.github.io/tsumitate-goal/
- 1枚のHTMLだけで動きます（外の部品・サーバーなし）。

目安の計算です。どれも過去の成績で、将来の運用の成果を約束するものではなく、特定の商品を勧めるものでもありません。
